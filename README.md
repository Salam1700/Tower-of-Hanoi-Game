# Tower of Hanoi Game

## Project Overview
The Tower of Hanoi Game is a Java-based desktop application developed for the Software Development I course. It allows users to play the classic Tower of Hanoi puzzle through a graphical user interface.

## Project Objectives
- Develop an interactive Tower of Hanoi game.
- Implement disk movement between three towers.
- Validate moves according to the game rules.
- Display the move counter and timer.
- Provide a restart option.
- Implement an automatic solver using recursion.
- Detect the completion of the puzzle.

## Technologies Used
- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **IDE:** NetBeans
- **Data Structure:** Stack
- **Algorithm:** Recursion
- **Version Control:** GitHub
- **Development Methodology:** Incremental Development

## Main Features
- Graphical user interface.
- Three towers and movable disks.
- Valid and invalid move handling.
- Move counter.
- Game timer.
- Restart functionality.
- Automatic solver.
- Winning condition detection.

## Project Structure
The project contains Java classes for the main application, main menu, game board, game controller, towers, disks, timer, game panel, and automatic solver.

## How to Download
1. Open this GitHub repository.
2. Click the **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.

## How to Run
1. Open NetBeans IDE.
2. Select **File → Open Project**.
3. Select the extracted NetBeans project folder.
4. Click **Run** to launch the application.

If the extracted folder is not recognized as a NetBeans project, the project configuration files may be missing. In that case, open or create a suitable Java project and add the source files.

## Game Rules
1. Only one disk can be moved at a time.
2. Only the top disk of a tower can be moved.
3. A larger disk cannot be placed on a smaller disk.
4. The objective is to move all disks from the source tower to the destination tower.

## Development Methodology
The project was developed incrementally over ten weeks, covering planning, system design, GUI development, game logic, automatic solving, testing, and documentation.
